### [SharkShell 🦈](https://github.com/sushilkumarsahani41/SharkShell)
**Secure, Self-Hosted Web SSH Client**

[![Stars](https://img.shields.io/github/stars/sushilkumarsahani41/SharkShell?style=flat-square&color=00d4ff&labelColor=0a1628)](https://github.com/sushilkumarsahani41/SharkShell/stargazers)
[![Docker Pulls](https://img.shields.io/docker/pulls/greatsharktech/sharkshell?style=flat-square&color=00d4ff&labelColor=0a1628&logo=docker)](https://hub.docker.com/r/greatsharktech/sharkshell)
[![License](https://img.shields.io/badge/License-AGPL_v3-blue?style=flat-square&color=00d4ff&labelColor=0a1628)](https://github.com/sushilkumarsahani41/SharkShell/blob/main/LICENSE)

</div>

> Multi-tab web SSH terminal with AES-256-GCM encrypted keystore, SSH key management, workspace persistence, and a single Docker command deployment. Built with React + NestJS + PostgreSQL.

```bash
# Deploy in one command
curl -sO https://raw.githubusercontent.com/sushilkumarsahani41/SharkShell/main/docker-compose.prod.yml
docker compose -f docker-compose.prod.yml up -d
# Open http://localhost:8080 🚀
```
